# Tech Stack

## Core Framework

- **Expo SDK** - Universal React Native platform for iOS, Android, and web
- **Expo Router** - File-based routing with native navigation

## Styling

- **Tailwind CSS v4** - Utility-first CSS framework
- **Uniwind** - Tailwind v4 for React Native (replaces NativeWind)
- **HeroUI Native** - React Native component library (Beta)
- **tailwind-variants** - Type-safe component variants with `tv()`

## Data & State

- **React Query (TanStack)** - Server state management and caching
- **AsyncStorage** - Local persistent storage

## Testing

- **Jest** with `jest-expo` preset - Unit testing
- **Storybook** - Component documentation and visual testing

## Development Tools

- **pnpm** - Package manager (required)
- **TypeScript** - Type safety
- **ESLint + Prettier** - Code quality and formatting
